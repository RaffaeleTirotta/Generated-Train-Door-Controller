# Train Door Controller (CATIA Magic-Generated C)

## Overview

This repository contains a C implementation of a **Train Door Controller** automatically generated from a **SysML** system model.

The project demonstrates a model-based systems engineering (MBSE) workflow where system requirements, behavior, and state machines are modeled in SysML and transformed into production-oriented C source code.

## Features

- Automatic door opening and closing logic
- State machine implementation generated from SysML
- Emergency door release support


## Generated Code

The C source files are automatically generated from the SysML behavioral model.

Generated components typically include:

- State machine implementation
- Transition logic
- Event dispatcher
- Input processing
- Output generation
